# Admin Dashboard Access Guide

## How to Access the Admin Dashboard

### Quick Start: Using the "Staff Login" Button ⚡

1. Go to the **login page**
2. Click the **"Staff Login"** button at the bottom (small gray text)
3. This will automatically:
   - Switch you to **signup mode**
   - Pre-fill email: `admin@tutornest.com`
   - Pre-fill name: `Admin User`
   - Show a success message guiding you
4. **Enter your password** (minimum 8 characters, e.g., `TutorNest2024!`)
5. **Confirm your password**
6. Click **"Create Account"**
7. You'll be automatically logged in with full admin access! 🎉

### Method 2: Manual Admin Account Creation

If you prefer to create your admin account manually:

1. Click **"Don't have an account? Sign up"** on the login page
2. Fill in the form:
   - **Email:** `admin@tutornest.com` (or any email with `admin@` in it)
   - **Name:** Your name
   - **Password:** At least 8 characters
   - **Confirm Password:** Same password
3. When you type an email with `admin@`, you'll see a blue alert:
   > **"Admin Account Detected"** - You're creating an admin account with full dashboard access
4. Click **"Create Account"**
5. Access your admin dashboard immediately!

### Future Logins (After Account is Created)

Once your admin account exists:

1. Go to the login page
2. Enter your credentials:
   - **Email:** `admin@tutornest.com`
   - **Password:** Your password
3. Click **"Proceed"**
4. Access your admin dashboard!

Or use the "Staff Login" button for quick email auto-fill.

### Admin Dashboard Features

Once logged in as admin, you'll have access to:

- **Real-time Analytics** - Platform metrics, user growth, revenue tracking
- **User Management** - View, search, filter, suspend/activate users
- **Live Activity Feed** - Monitor all platform activities in real-time
- **Tutor Verification** - Review and approve/reject tutor applications
- **Financial Dashboard** - Track revenue, payouts, and transactions
- **Platform Settings** - Configure system-wide settings
- **Support System** - Manage user support tickets and inquiries

### Troubleshooting

**Can't find the "Staff Login" button?**
- Make sure you're on the sign-in page (not sign-up)
- Look at the very bottom of the login form
- The button appears as small gray text for security

**Already logged in as another role?**
- Sign out first
- Return to the login page
- Use the "Staff Login" button or enter admin credentials manually

**Forgot admin password?**
- Click "Forgot password?" on the login page
- Enter `admin@tutornest.com`
- Check your email for the reset link

---

**Security Note:** The admin login is intentionally subtle to prevent unauthorized access attempts. Only authorized staff should use this login method.
