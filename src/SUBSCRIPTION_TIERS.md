# TutorNest Subscription Tiers

## Overview

TutorNest offers three subscription tiers designed to accommodate families of different sizes and learning needs. Each tier is differentiated by:

1. **Number of Children** - Maximum child profiles allowed
2. **Sessions Per Child** - Monthly session allocation per child
3. **Features & Support** - Access to platform features and support levels

## How Child Limits Work

### Adding Children

1. **Basic Tier**: Can add 1 child profile
2. **Standard Tier**: Can add up to 2 child profiles
3. **Premium Tier**: Can add up to 4 child profiles

### Enforcement

- When adding a child, the system checks your current subscription tier
- If you've reached your tier's child limit, you'll be prompted to upgrade
- The "Add Child" button will show upgrade options when limit is reached

### Upgrading for More Children

**Example Scenario:**
- You're on Basic tier with 1 child
- You try to add a second child
- System blocks the action and suggests upgrading to Standard or Premium
- Upon upgrade, you can immediately add the additional child(ren)

## Session Allocation

### Per-Child Allocation

Sessions are allocated **per child**, not shared across children:

**Basic:**
- 1 child × 4 sessions = 4 total sessions/month

**Standard:**
- 2 children × 10 sessions each = 20 total sessions/month
- Example: Child A can have 10 sessions, Child B can have 10 sessions

**Premium:**
- 4 children × 20 sessions each = 80 total sessions/month
- Example: Each of 4 children can have up to 20 sessions

### Session Tracking

- Sessions are tracked per child individually
- Unused sessions from one child cannot be transferred to another
- Sessions reset at the start of each billing cycle

## Upgrading & Downgrading

### Upgrading

**When:** You need to add more children or want more features

**How it works:**
1. Choose a higher tier (e.g., Basic → Standard)
2. Pro-rata billing applies immediately
3. You pay only the difference for remaining days
4. Child limit increases immediately
5. Additional features activate instantly

**Example:**
- Currently on Basic (£29.99) with 15 days left in billing cycle
- Upgrade to Standard (£59.99)
- Pay ~£15 pro-rata charge
- Can immediately add second child

### Downgrading

**When:** You want to reduce costs or need fewer children slots

**How it works:**
1. Choose a lower tier (e.g., Standard → Basic)
2. Downgrade scheduled for next billing cycle
3. Receive credit for price difference
4. Continue with current features until cycle ends

**Important Consideration:**
- If you have more children than the new tier allows, you must:
  - Remove excess children before downgrade, OR
  - Wait until next billing cycle to remove children
- System will prevent downgrade if it would violate child limits

## Technical Implementation

### Backend Enforcement

```typescript
// Child limit check in parent-children-routes.tsx
if (currentChildCount >= subscription.maxChildren) {
  return error: {
    message: "Tier limit reached",
    requiresUpgrade: true,
    currentTier: subscription.tierName,
    maxChildren: subscription.maxChildren,
    availableTiers: [...higher tiers...]
  }
}
```

### Frontend Validation

```typescript
// Check before showing "Add Child" dialog
const canAddResponse = await fetch(
  `/subscription/${parentId}/can-add-child`
);

if (!canAddResponse.canAdd) {
  // Show upgrade prompt instead of add child dialog
}
```
